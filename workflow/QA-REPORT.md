## 2. 视觉 QA

**代码评审看不见** 16px 的布局位移、重叠的侧栏、渲染成空白的状态。本项目用**已有的造图机**
（`scripts/shots/`，CDP + 合成 fixture），不要另起 Playwright。

```bash
# 前置：一个装好本插件的独立 DSH 实例（不要在 3080 日常实例上跑，脚本会拒绝）
DSH_HOME=/tmp/dsh-quota-demo dsh plugin --profile web add <本仓库路径>
DSH_HOME=/tmp/dsh-quota-demo dsh web --port 3099 --no-open

# 标准取景（1280×860，写进 docs/images —— 中英各跑一次）
node scripts/shots/make-shots.mjs --url http://127.0.0.1:3099 --lang zh --out docs/images
node scripts/shots/make-shots.mjs --url http://127.0.0.1:3099 --lang en --out docs/images

# 窄视口（新增：--width / --height；非默认取景拒绝写入 docs/，必须落到 .shots-work/）
node scripts/shots/make-shots.mjs --url http://127.0.0.1:3099 --width 375 --out .shots-work/narrow
node scripts/shots/make-shots.mjs --url http://127.0.0.1:3099 --width 768 --out .shots-work/narrow
```

看什么（逐张读图，不要只看文件大小）：

- [ ] 溢出 / 裁切：文字被截断、徽标超出容器、面板被窗口边缘切掉
- [ ] 布局完整性：与标准取景相比，元素没有错位或重叠
- [ ] 状态真的渲染了：空 / 加载 / 错误态不是一片白
- [ ] **口径正确**（这是产品立场，画错等于 README 打自己脸）：实测卡**没有**进度条、**没有**百分比；带数字的官方卡才有分母
- [ ] 对比度与可读性；焦点态可见
- [ ] 视觉**变更**时补 `main` 与分支的前后对比

## 3. 已知的流水线边界（如实记录，别当成"QA 过了"）

- 造图机固定 **1280×860** 起景、并按元素矩形裁切；`--width/--height` 是本次新增的能力。
- 窄视口下若报 `point-outside-viewport` 或裁切超界：**这本身是产品信号**——先判断是布局问题还是取景问题，别直接改流水线绕过去。
- 图是**合成数据**（`assertFixture` 拦真实痕迹）。要证明真实上游契约，那是 `probe` 与 `docs/upstream-contracts.md` 的事，不是截图的事。
