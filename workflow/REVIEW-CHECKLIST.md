## Lens 1 — 正确性与健壮性

这一 lens 找的是**能活过 `npm run check` 的那类缺陷**。

- [ ] **方向与单位**：每个数值都知道自己是"剩余 / 已用 / 差额 / 增量"哪一种。已知陷阱：OpenRouter 余额 = `total_credits - total_usage`（差额）；xAI `total.val` 是取负的整数分；Gemini `remainingFraction` 是**剩余**而 Anthropic `utilization` 是**已用**（方向相反）。接错 = 仪表反向。
- [ ] **信封路径**：取数前先判上游信封（如 Moonshot `code==0 && status==true`）再取 `data.*`；路径按 `docs/upstream-contracts.md` 写的来，不是"看起来像"的那个。
- [ ] **分母规则**：没有官方分母就不出现百分比；**实测卡永不画余量条、永不显示百分比**——服务端和 `lib/client.js` 两边都要禁（只禁一边等于没禁）。
- [ ] **绑定与可见性**：新数据源/别名的 `bindProviders` 与真实在用路由是否真能对上？`panelScope: current` 下对不上的卡会**静默消失**（不是报错，是看不见）。
- [ ] **部分失败**：多源查询中一个源超时 / 401 / 返回非 JSON 时，其它卡与徽标怎么表现？错误路径不得把整个面板拖垮。
- [ ] **降级链**：凭据缺失、Cookie 掉线（→ 不带任何数字的错误卡 + 实测兜底仍可见）、无历史数据（→ "无官方额度数据"）三条路径都还成立吗？
- [ ] **幂等与缓存**：`/refresh` 覆盖快照、轮询节流；重试会不会把同一次统计算两遍。
- [ ] **只读**：没有新增任何可能产生计费的请求（"探活""预热"都不行）。
- [ ] **资源生命周期**：客户端定时器 / 事件监听 / DOM 座位探测在面板卸载与座位消失时释放。
- [ ] **测试完整性**：diff **测试本身**——断言有没有被弱化、测试有没有被跳过/删除、期望值有没有被改；`fixture.mjs` 的 `assertFixture`（真实痕迹、`publicCard()` 白名单外的键、实测卡带百分比）有没有被绕过。逐条问：**如果这个功能坏了，这个测试还会通过吗？**

## Lens 2 — 安全与信任边界

- [ ] **凭据只进不出**：密钥 / Cookie 的值不出现在路由响应、日志、错误信息、tooltip、快照、截图里。文档与提交信息里只允许出现**键名**。
- [ ] **出站主机**：实际出站主机集合 == `dshhub.permissions.network` 声明集合（新增一个就同步一个，`check-manifest.mjs` 会核）。
- [ ] **注入**：上游返回的文本（供应商名、错误串、模型名）进 tooltip / 面板 / 徽标时转义了吗？Cookie 回退路径的输入校验了吗？
- [ ] **零依赖**：`package.json` 没有 `dependencies`。真需要新依赖时：精确包名在注册表存在、是你以为的那个包、仍在维护（拼写相似的假包被真注册过——slopsquatting）。
- [ ] **外壳差异**：`conversation.input.left` 座位探测与"老外壳拿不到 react-dom"的降级路径，没有引入样式注入或 DOM 注入。
- [ ] **合成数据**：`scripts/shots/` 的 fixture 与截图里**不得**出现真实余额、真实用户名、真实盘符路径（这些图会公开在 README 与 npm 页）。

## Lens 3 — 计划一致性与完整性

- [ ] 计划里的每一步都实现了，或**明确推迟并同步改了计划**。
- [ ] diff 里没有计划之外的东西；**非目标**确实没被碰。
- [ ] **diff 文件清单无意外**——清单里出现没预期的文件，是最快的范围蔓延探测器。
- [ ] **复用检查**：每个新 helper / 工具函数，都搜过代码库里是否已有同类（`normalizeSources` / `publicCard` / `PRESETS` / `SOURCE_META` / `PLATFORM_RULES` / `ERROR_HINTS`…）。
- [ ] 对外描述与代码同源：`README.md`、`README.en.md`、`dshhub.summary`、`docs/*`（`check-docs.mjs` 的第 1–9 项会核；中英两份都要）。
- [ ] 截图契约：`docs/images/` 与 `screenshots.json` 一致、README 已引用（第 10 项）。
- [ ] CHANGELOG / 版本 / tag 同步（第 7 项）；`RELEASE.md` 与提交条目同源。
- [ ] **`AGENTS.md` 与 `workflow/` 仍然准确**——这次改动有没有让它们某一行失效？
- [ ] README 的"明确不做的三类"没有被越界（要改决策先改文档）。
