# 025 方案

## 方案 A（采纳）模块内加一行，仅 estimate 口径渲染

文案只讲「按忙时价目、未计夜间折扣、实际更多」三件事，不引入新数字。挂在 estimate 分支上，因此
回落 019 capacity 时不会出现一句与数字无关的说明。

- 为什么放模块内而不是整页脚注：用户指定的位置是「如果只用单个模型」这一块，024 之后整页脚注只剩来源行，
  再往里塞口径句会让脚注重新膨胀。
- 为什么不一并说明夜间折扣的倍率：qwen 4 折、deepseek 5 折，且折扣是否与忙时价目简单相乘未取证；
  写死倍率等于给一个未经核对的换算，反而制造第二个口径。
- 为什么用 11px 而不是 023 之前的 10.5px：023 删掉的那批小字是 10.5px 三层堆叠；这里只留一行，11px 保证可读。

## 方案 B（否决）改成 tooltip / 折叠

面板没有折叠交互，新增交互面超出这次文案改动的范围。

## 方案 C（否决）直接改估算数字（乘折扣）

会让主数字与官方口径脱钩，且夜间/忙时比例未知；用户要的是「解释没算折扣」，不是「算上折扣」。
