# SPEC — 011 柱子悬停看当时的 tokens

## 背景（用户 2026-11-14 提出）

用户贴了千问平台自己的「Token Plan 用量分析」页面（按天柱状图 + 悬停数值），说：官方也有统计，加一个功能——**鼠标放上去能看到当时用了多少 token**。

现状：统计屏的柱状图（2D / 3D、日桶 / 周桶）每根柱只有一个原生 SVG `<title>`，
悬停要等系统提示框（约 1 秒、系统样式、位置跟系统走），且和页面视觉完全不搭；
用户要的是「指上去马上看到这一根柱的 tokens」。

## 目标

1. 悬停任意一根柱（2D / 3D、日 / 周）**立即**显示自己实现的浮层：日期（或周区间）+ 总量 tokens + 四类拆分 + 调用次数。
2. 触屏可点开；键盘 Tab 到柱上也能看到。
3. 全部是**绝对 tokens**，不出现百分比、不出现 Credits、不出现估算值。
4. 不改变柱高、刻度、峰值标签、布局：除浮层外截图逐像素不变。

## 非目标

- 不做缩放/框选/点击下钻；不做跨设备用量（那是账号侧数据，本仓口径不折算）。
- 不改宿主：`buckets` 已经带 `from` / `to` / `label` / `totals`，无需新接口、新配置键、新路由、新出站主机。
- 不加新 i18n 键：文案全部复用总量卡与拆分格已有的键（避免两处措辞漂移）。

## 用户故事

- 作为看用量的人，我把鼠标放到 11-13 那根柱上，能立刻看到「11-13 / 总量 / input / output / cacheRead / cacheWrite / 调用次数」。
- 作为用键盘的人，我 Tab 到柱子时也能看到同一份数字（读屏读的是同一句）。
- 作为用触屏的人，我点一下柱子能看到，点空白处关掉。

## 需求

- **FR-001 命中**：任意一根柱（2D 的整根矩形、3D 的三面整体）都是命中区；同一时刻只有一个浮层。
- **FR-002 立即**：指针进入柱子即显示，不等系统提示框；离开即隐藏。
- **FR-003 内容**：首行日期（日桶 `YYYY-MM-DD`；周桶 `YYYY-MM-DD – YYYY-MM-DD`），其后总量、input、output、cacheRead、cacheWrite、调用次数，数字用与总量卡相同的 `formatTokens`。
- **FR-004 位置**：跟随指针偏移；靠近视口右/下边缘时自动翻转或夹紧，不越界、不遮住指针。
- **FR-005 关闭**：离开该柱、按 Esc、横向滚动图表、指针按下别处、窗口失焦 → 隐藏。
- **FR-006 键盘**：每根柱可 Tab 聚焦（`tabIndex=0`、`role="img"`、`aria-label` 为同一份文本），聚焦显示、失焦隐藏。
- **FR-007 触屏**：`pointerdown`（touch）显示，点别处 / Esc 关闭；不阻断图表横向滚动。
- **FR-008 不再双提示**：移除原生 `<title>`（保留 aria-label），否则会和自定义浮层同时弹出。
- **FR-009 口径**：任何情况下不出现 `%` 与 `Credits`；0 桶照实显示 0。
- **FR-010 无 react-dom 回退**：宿主没有 `react-dom` 种子词时退回内联绝对定位（与现有悬浮面板同款策略），功能不丢。

## 验收

- **SC-001** 悬停 10-22 那根柱，屏上出现浮层且首行是 `2026-10-22`、总量等于该桶 `totals.tokens`（与 fixture 逐字相等）。
- **SC-002** 2D 与 3D 悬停同一根柱，内容一致。
- **SC-003** 周桶悬停首行是 `from – to`，不是单日。
- **SC-004** 指针移到视口右下角附近，浮层仍在视口内（左/上/右/下四边都留 ≥8px）。
- **SC-005** Esc / 滚轮 / 指针移出柱 → 浮层消失；同一时刻只有 1 个 `[data-usage-tip]`。
- **SC-006** Tab 到柱子出现浮层、失焦消失；`aria-label` 与浮层文本同源。
- **SC-007** 中英界面浮层文案都不含 `%`、`Credits`，且英文界面不混中文。
- **SC-008** 除浮层外，记账屏的 2D / 3D 柱图几何与既有截图一致（柱高、刻度、峰值标签不变）。
- **SC-009** 宿主零改动：`test/host.mjs` 仍是 855 项且全绿；无新配置键、无新出站主机。
