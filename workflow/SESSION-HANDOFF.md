## DSH 上的具体做法

- **想开新会话**：在新会话里第一句就指向 `AGENTS.md` + 本文件 + 计划文档；工件是存档点，聊天记录不是。
- **想留在同一会话**：让 agent 在相位边界自查上下文占用，过 40% 就按上面的判据决定"压缩还是开新会话"。
- **想要独立上下文的评审**：用 `subagent`（自带上下文窗口），把 diff + 计划给它，**只读**——这是三条 lens 的前提。
- **探索类问题**（"找出所有调用 X 的地方"）丢给 `subagent`，只把一行结论带回来，别把十个文件读进主会话。
- **失败尝试是有毒残留**：同一步骤三次失败就回滚到最后好的 commit 并重开环节，而不是继续在同一上下文里试第四次。
