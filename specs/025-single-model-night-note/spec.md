# 025 单模型估算补一句夜间折扣说明

状态：进行中（2026-11-15）
关联：019（单模型容量）、022（按官方价目估算）、023（独立模块）、024（撤掉说明性脚注）

## 背景

022 的估算用的是官方**忙时**价目。夜间 22:00–08:00 官方打 4–5 折，同样的 Credits 在夜间能换到更多 tokens，
所以卡片上的数字是保守下界。用户（m01841）要求把这件事说清楚：

> 「「如果只用单个模型」加上一个解释用来解释这事没有算上夜间折扣的情况下，昨晚之后就发版」

024 刚把面板上的说明性小字全部撤掉，本条是有意的例外：用户点名要这一句，且只解释一个会影响读数方向的限制。

## 目标

- FR-001 在「如果只用单个模型」模块内加一行说明，文案逐字：
  zh「按官方忙时价目估算，未计 22:00–08:00 夜间折扣；实际可用 tokens 会更多。」
  en "Estimated from peak-hour list prices; the 22:00-08:00 discount is not included, so the real capacity would be higher."
- FR-002 只在走了 022 estimate 口径时渲染（`estimate !== null`）；回落到 019 `capacity` 时不渲染——占比折算与价目无关。
- FR-003 位置在结果卡之后、模块容器（`div.tpq-usage-credits-modelpick`）内的最后一个子节点，类名
  `p.tpq-usage-single-model-note`；不新增容器、不改 module 与 chips / card 的既有钩子。
- FR-004 COPY 新增两个键（中英各一）：`usageSingleModelNightNote`；键数 152 → 153。
- FR-005 数据口径零变化：不改估算公式、不新增路由 / 配置键 / 出站主机 / 依赖；宿主 `lib/index.js` 不动。
- FR-006 同步测试与守卫：client 断言文案与渲染条件，guards 新增第 25 节静态矩阵并更新 COPY 计数。

## 非目标

- 不用折扣率重算估算值（官方夜间折扣是否与忙时价目线性相乘未取证；只说明方向，不给第二个数字）。
- 不做 019 / 022 的手动口径切换（用户没要）。
- 不重拍 docs 截图（读图通道不可用，022 已写明）。
