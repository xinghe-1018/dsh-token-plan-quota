# 024 方案

## 方案 A（采纳）整块删掉，不换成更短的说明

用户要的是「屏上不要这些解释」，不是「换一种说法」。把六个文案键连同 DOM 与 CSS 一起删，面板只剩数据：
Credits 换算卡、三格卡片、模型行、官方对照、占比条。口径说明继续留在 README 与规格文档里。

- 为什么不留一句最小提示：删一半会留下「为什么只有这三格」「这些数怎么来的」的悬空感，反而更容易误读；
  用户已经明确不要小字，留一句等于抗命。
- 为什么不放到 tooltip / 折叠区：面板没有折叠交互，新加交互面超出这次文案改动的范围。

## 方案 B（否决）改成更短的脚注

仍然是脚注，仍然在回答「怎么算」。用户要删的就是这个位置。

## 方案 C（否决）删文案但保留键

死键会被 guards 的键数断言与 i18n 完整性检查盯住，也会让下一个维护者以为还能打开。直接删干净。
